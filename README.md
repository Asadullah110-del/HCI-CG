# HCI-CG# Mini Assignment: Deconstructing HCI & Computer Graphics

## Google Earth

This mini assignment analyzes **Google Earth** from two perspectives:
**Human-Computer Interaction (HCI)** and **Computer Graphics (CG)**.

The purpose of this assignment is to understand how interactive controls
help users interact with software and how computer graphics create a
realistic 3D environment.

---

## HCI Focus

The first screenshot identifies three important interaction elements
in Google Earth.

### 1. Search Bar
The Search Bar allows users to quickly find places, landmarks, cities,
and other locations.

### 2. 3D Navigation
The 3D navigation controls allow users to change their viewing direction
and explore locations from different angles.

### 3. Zoom Controls
The Zoom controls allow users to zoom in and out of the map, making it
easy to examine locations at different levels of detail.

![Google Earth HCI](google_earth_hci.png)

---

## Computer Graphics Focus

The second screenshot identifies three important computer graphics
elements in Google Earth.

### 1. Lighting and Shadows
Lighting and shadows make buildings and terrain appear more realistic
and help users understand depth and position.

### 2. 3D Mesh Geometry
3D mesh geometry represents buildings and terrain as three-dimensional
objects, creating a realistic digital environment.

### 3. Texture Mapping
Texture mapping adds surface details to buildings and terrain, making
the environment look more similar to the real world.

![Google Earth Computer Graphics](google_earth_cg.png)

## Reflection

### 1. How does the Computer Graphics quality help or hinder the user's ability to interact with the software?

High-quality graphics such as realistic 3D views, lighting, and shadows
help users understand locations, depth, and scale. This makes Google
Earth easier and more engaging to explore. However, detailed graphics
may require more processing power and can make the software less
responsive on lower-end devices.

### 2. What is one simple HCI change you would make to improve the user interface?

I would add clearer labels or tooltips for the main navigation controls,
such as the compass, 2D/3D button, and zoom controls. This would help new
users understand what each control does and make Google Earth more
beginner-friendly and easier to use.
